## About This Repository

这是我的个人技术成长仓库，核心是 **算法竞赛与问题求解**，同时记录 AI、机器学习、课程实验和软件项目。

`Algorithms/` 目前收录了 **800+ 个 C++ 代码文件**。内容以日期组织，持续覆盖 Codeforces、AtCoder、ICPC/CCPC、Nowcoder 和 Luogu 等平台，既有正式比赛与补题，也有基础算法模板和专题训练。

> Think clearly. Code precisely. Improve continuously.
